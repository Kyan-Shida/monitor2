# 01 · 巡检点导入入口改造：一个入口、两条路径

> 变更类型：UI 结构重构 + 小范围数据模型扩展
> 变更日期：2026-10-06
> 影响模块：巡检点管理 → 巡检点导入

---

## 一、变更目标

把「巡检点管理」原来的单一按钮「导入巡检点标定文件」改造为**一个「巡检点导入」入口**，
点击后打开右侧抽屉，抽屉内提供**两条路径二选一**：

| 路径 | 说明 |
|---|---|
| ① 批量文件上传 | 先明确**数据来源机器人（机器狗）**，再选择「从机器人拉取数据」或「上传表格文件」 |
| ② 实时标定点 | 在底图上实时打点补录定位点，随后（行内）编辑巡检项 |

> 口径来源：客户记录确认 —— 「数据方向是机器人/前端 → 平台」「先明确上传的是哪只狗的数据」
> 「实时标点后编辑巡检项（复用现有能力）」。

## 三、核心逻辑说明

### 3.1 批量文件上传的前置条件
未选择「数据来源机器人」时，抽屉内**不出现**「拉取数据」与「上传表格文件」，
只提示"请先选择数据来源机器人"。切换机器人时 `TableUploadPanel` 以 `key={robotId}` 重置，
避免把 A 狗的解析结果导到 B 狗名下。

### 3.2 「从机器人拉取数据」的诚实降级（🔴 不造假数据）
项目**尚未接入机器人端数据接口**。按"禁止模拟数据"口径：
- 不返回任何假装的数据；
- 以 ERROR 级记录完整错误信息（前端用 `console.error`，符合前端日志规范：`console.error` 保留）；
- 界面给出明确原因与替代路径（改用「上传表格文件」）。

```ts
function pullFromRobot() {
  console.error("[巡检点导入] 从机器人拉取数据失败：机器人端数据接口未接入", { robotId, robotName: robot?.name });
  SETPULL(`机器人端数据接口未接入，暂时无法从「${...}」拉取巡检点数据。...`);
}
```

### 3.3 表格文件解析（复用，不新增依赖）
沿用 `parsePointCalibration()`：支持 **CSV / TXT / JSON**，解析不出即报错（不生成模拟数据）。
本次**未引入 `xlsx`**（上轮已移除），因此界面文案统一为「上传表格文件」，不承诺 `.xlsx`。

### 3.4 来源机器人只作归属
`robotId` 随标定数据落库，仅作**数据来源归属**，不参与定位计算：
定位仍以 `定位 ID（externalId）` + （后续）统一坐标系 `world` 为准。

## 四、数据结构变更

| 类型 | 新增字段 | 说明 |
|---|---|---|
| `MapCalibration`（`mapCalibration.ts`） | `robotId?: string` | 采集该批点位数据的机器人 |
| `PendingCalibration`（`mapCalibration.ts`） | `robotId?: string` | 暂存时一并保留 |
| `State`（`types.ts`） | 无 | 复用既有 `mapCalibrations` / `pendingCalibration` |

**action 载荷**（`Action` 为宽松类型 `{ type: string; [k: string]: any }`，无需改联合类型）：

| action | 新增载荷 | 行为 |
|---|---|---|
| `IMPORT_POINT_CALIBRATION` | `robotId?: string` | 绑定分支：`cal.robotId = a.robotId \|\| cal.robotId`；暂存分支写入 `pendingCalibration.robotId` |
| `BIND_PENDING_CALIBRATION` | — | `cal.robotId = pending.robotId ?? cal.robotId` |

## 六、注意事项与遗留

1. **「实时标定点」目前是"图上打点"**，尚未接入机器人实时位置流；
   客户所称"实时显示机器人在当前地图上的位置"属后续优化（前端戳点路径③亦为规划项）。
2. **行内「编辑巡检项」**：已绑定 → 进入该巡检点编辑页；未绑定 → 进入新建页。
   新建页暂**未预填**当前标定点/地图（需手选），属可优化点（需给 `point-edit` 增加预填参数）。
3. 「上传表格文件」不承诺 `.xlsx`；若后续确认需真 Excel，需重新引入 `xlsx` 并补解析。
4. 来源机器人在标定核对面板的说明文字中展示（`数据来源机器人：xxx`）。

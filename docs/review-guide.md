# 页面评审开关

顶栏“页面评审：关闭”开关默认关闭。开启后出现“评审意见”入口，可选择页面元素标注、填写意见、按页面/全部汇总、一键复制，以及导出/导入 JSON 或 Markdown。关闭会退出标注并隐藏评审面板，已保存意见不会删除。开关与意见均保存在当前浏览器；多人意见需导出 JSON 后汇总导入，不依赖后端。

# 原型评审指南

评审地址：[http://123.56.9.124:5173/](http://123.56.9.124:5173/)

1. 打开需评审的页面，点击右上角 **评审意见**。
2. 点击 **点击页面标注**，再点击页面上需要反馈的元素。整页问题可直接点击 **添加整页意见**。
3. 填写姓名或团队、类别、优先级、具体问题和期望效果，点击 **保存意见**。可以在不同页面连续添加多条。
4. 评审结束点击 **导出数据 JSON**，把文件发给原型负责人；也可以点击 **下载 Markdown**，把文件直接发给 Codex 使用。

原型负责人收到多人 JSON 后，打开同一地址，点击 **评审意见 → 导入多人意见**，一次选择多个文件；面板会合并并去重。点击 **一键复制**，将文字粘贴到当前 Codex 任务即可，也可直接把导出的 Markdown 文件附在任务中。

意见只保存在当前浏览器。请在清理浏览器数据或换设备前先导出。页面业务演示数据同样是浏览器本地数据，评审人之间互不影响。

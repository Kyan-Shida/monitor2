## AI 上下文速查
1. **技术栈**：React 19 + TypeScript 5 + Vite 5 + lucide-react；纯前端，状态存 localStorage（`data/store.tsx`）。
2. **数据模型关系**：Task(state 含 `已被接管`) → items(Point) → results(Result)；Point(world 权威坐标 + mapId 仅来源) → BusinessTarget(仪表/环境/区域) → Instrument；Alarm(resultId/taskId/pointId/robotId + validity)；Session(origin: 人工主动|机器人申请)。
3. **服务端口**：`npm run dev` → 5175（被占用时自动 +1）。
4. **核心调用链**：UI → `act()`（`engine.ts` reducer）→ `useStore` 持久化 → 重渲染。
5. **启动/验证命令**：`npm test`（62 项全绿）；`npm run dev`；静态导出 `node scripts/export-static.mjs`。
6. **配置**：`vite.config.ts`、`tsconfig.json`（strict:false）、`.npmrc`（国内镜像）。
7. **本阶段新增依赖**：无。
8. **注意事项**：`npm run build`（`tsc -b && vite build`）在 Windows 下直接跑存在入口解析问题；以 `npm run dev` 或 `export-static.mjs` 为准。
9. **待确认项（方案，仅记录不改 UI）**：TGT-03（B-1）、TASK-01（B-2）、RES-04（B-3）、PT-04（B-4）、TKO-02（B-5）、SYS-01（B-6）、PT-06/B-7、MAP-03/B-8。
